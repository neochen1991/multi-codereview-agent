项目隔离边界
后端不能只做页面筛选，检视链路每一步都必须带 project_id。
代码仓隔离 创建审核时只能选择当前项目绑定的仓库，自动拉 MR 也按项目遍历。
知识库隔离 规范文档、结构化规则和检索结果都只来自当前项目。
专家配置隔离 内置专家全局复用，项目可以覆盖启用状态、规范绑定和工具权限。
结果隔离 审核历史、问题清单、过程消息、影响报告全部按项目存取。

审核链路中的项目上下文
这里对应后端实现，不是单纯页面筛选。
1 选择项目 Header 或侧边栏确定当前 project_id。
2 创建审核 任务写入 project_id 和 repository_id。
3 组装上下文 读取项目代码仓、规范、专家配置和图谱。
4 执行检视 Agent 只能调用当前项目允许的工具和数据源。
5 沉淀结果 问题、消息、报告都写回项目空间。
